# Live advisor startup

The Tavus conversation uses `custom_greeting` as the primary greeting. The custom Daily UI also listens for Tavus speaking events. If the replica has not started speaking after the remote participant joins, the client sends the same greeting through the Tavus `conversation.echo` interaction. This avoids a silent avatar while preserving the normal Tavus greeting when it works.

The brand strip intentionally includes 4BID, Santaddeo, HotelAccelerator, HotelProfit AI and ManuBot. HotelAccelerator and HotelProfit AI use explicit text labels next to their marks so wide or whitespace-heavy source assets remain readable.
